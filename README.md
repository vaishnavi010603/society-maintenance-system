# 🏢 Society Maintenance Management System

A containerized internal web application designed to manage monthly maintenance payments, expenses, reporting, and backups for a housing society.

Built and deployed using Linux (RHEL 9) and Podman.

---

## 🚀 Features

- 🔐 Chairman login authentication (session-based)
- 📅 Automatic month detection (no manual editing required)
- 💰 Mark maintenance payments
- 🧾 Add and track expenses
- 📊 View dynamic monthly financial report
- 📄 Download report as PDF
- 📧 Email monthly report via Gmail SMTP
- 💾 Download full data backup (ZIP)
- 🐳 Containerized using Podman (Docker-compatible)

---

## 🛠 Tech Stack

| Component        | Technology Used |
|------------------|-----------------|
| Backend          | PHP + Apache    |
| Frontend         | HTML + CSS      |
| OS               | RHEL 9 VM       |
| Containerization | Podman          |
| PDF Generation   | TCPDF           |
| Email Service    | PHPMailer + Gmail SMTP |
| Data Storage     | CSV files       |
